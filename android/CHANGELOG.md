# Android release notes

## 1.2.3

- Added native words-per-minute speed control alongside the ECI speed scale.
- Added manual pitch selection in hertz while retaining the ECI pitch option.
- Added an optional equalizer with Balanced, Warm, Bright, Smooth, and Custom presets.
- Added five advanced parametric equalizer filters with frequency, gain, and bandwidth controls.
- Added optional scheduled stable-release checks and update notifications.
- Kept automatic update checks limited to published stable releases; prereleases and drafts remain excluded.
- Preserved EVDroid-compatible emoji, number, punctuation, camel-case, and regular-expression dictionary processing.
- Preserved the existing pronunciation dictionary manager and Android Direct Boot behavior.
